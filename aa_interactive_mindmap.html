How is the signature made?

Turning calldata into a 32-byte digest, signing with Anvil/Private key, packing (v, r, s).

getUserOpHash() toEthSignedMessageHash() vm.sign(key, digest)
3. The Validation Loop Phase 1: Security & Gas

Ensures Bundler won't lose gas fees, recovers signer via ECDSA, pays missingFunds.

⚠️ Crucial Invariants (Why Tests Fail If Mismatched)

1. Signer Key == Wallet Owner If ANVIL_DEFAULT_KEY signs, the recovered address is 0xf39Fd6.... Ownership in DeployMinimal must be transferred to config.account, NOT msg.sender!
2. EntryPoint Initialization getOrCreateAnvilEthConfig() must return address(entryPoint), not address(0), and cache to localNetworkConfig.
